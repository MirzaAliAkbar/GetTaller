## 📸 Technical Requirements

### Dimensions
- **Android:** 1080 x 1920 px (9:16 ratio)
- **iOS:** 1170 x 2532 px (19.5:9 ratio)
- **Format:** PNG or JPG (RGB, not CMYK)

- Use actual app screens (not mockups)
- Add text overlays for clarity
- Use your app's color scheme (purple gradient)

- 3-5 second glance readability

## 🎨 Design System for All Screenshots

### Colors:
- **Primary Purple:** #667eea (gradient start)
- **Secondary Purple:** #764ba2 (gradient end)
- **Accent Green:** #4CAF50 (growth, progress)
- **Text:** White (#FFFFFF) with slight shadow
- **Background:** Match app's gradient

### Typography:
- **Headline:** 40-48px, bold, white, top center
- **Subheading:** 20-24px, regular, white, slightly transparent
- **Body text:** 16-18px, regular, white

### Shadows & Effects:
- Text: 2-3px black shadow (0.3 opacity) for readability
- Cards: Subtle drop shadow (4px, 0.15 opacity)
- Gradients: Subtle, not overwhelming

## 📸 How to Take Screenshots

### **Android:**
```bash
# Method 1: Using adb
adb shell screencap -p /sdcard/screenshot.png
adb pull /sdcard/screenshot.png

# Method 2: Physical device
Power + Volume Down (hold 1-2 seconds)
```

### **iOS:**
```bash
# Method 1: Physical device
Side button + Volume Up (simultaneously)

# Method 2: Simulator
Cmd + S (or Device → Screenshot)
```

### **Best Approach:**
Use your **actual app running on device**. This shows:
- Real data (authentic)
- Real UI (credible)
- Real performance (builds trust)
