## Issue 2: 10-Second Black Screen on Every Launch

**Root cause:** `runApp()` is NOT called until ALL services finish initializing sequentially. The worst offenders:

1. **Remote Config `fetchAndActivate()`** — has a 60-second timeout! Called via `AiService.initialize()` even when build-time key is provided
2. **MobileAds `initialize()`** — network call, slow
3. **NotificationService `init()`** — platform channels
4. **UserDataService migration** — disk I/O

**Fix:** Move non-critical services to fire-and-forget AFTER `runApp()`. Only await Firebase + Hive (both fast/necessary).

### Optimized init flow:

```
1. Firebase.initializeApp()        ← MUST await (everything depends on it)
2. HiveService.init()              ← MUST await (data access needed immediately)
3. runApp()                        ← SHOW THE APP IMMEDIATELY
4. AiService().initialize()        ← fire-and-forget (not needed at first screen)
5. NotificationService().init()    ← fire-and-forget
6. MobileAds.instance.initialize() ← fire-and-forget
7. UserDataService().migrate...()  ← fire-and-forget
```
