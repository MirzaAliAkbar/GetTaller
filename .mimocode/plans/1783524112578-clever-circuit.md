# Plan: Fix Notification Icon Using App Icon

## Problem
The notification icon fails to initialize, crashing the app. The root cause:
- Plugin searches for icon in `drawable-*` folders but icon is only in `mipmap-*` folders
- `@drawable/` prefix causes double-prefixing
- Vector XML in unqualified `drawable/` doesn't survive build

## Solution
Generate notification icon PNGs from the existing app icon and place them in the correct drawable folders.

## Steps

### Step 1: Generate PNG notification icons from app icon
Convert the existing `mipmap-xxxhdpi/ic_launcher.png` (or use ImageMagick/ffmpeg) to create white monochrome PNGs at each density:
- `drawable-mdpi/ic_launcher.png` (48x48)
- `drawable-hdpi/ic_launcher.png` (72x72)
- `drawable-xhdpi/ic_launcher.png` (96x96)
- `drawable-xxhdpi/ic_launcher.png` (144x144)
- `drawable-xxxhdpi/ic_launcher.png` (192x192)

### Step 2: Delete broken vector XML
Remove `android/app/src/main/res/drawable/ic_notification.xml`

### Step 3: Update notification_service.dart
Remove `@drawable/` prefix from ALL icon references:
- `AndroidInitializationSettings('ic_launcher')` (no prefix)
- `icon: 'ic_launcher'` in all AndroidNotificationDetails

### Step 4: Clean build & increment version to 1.0.0+11
```bash
flutter clean
flutter pub get
flutter build appbundle --release --dart-define=OPENCODE_ZEN_API_KEY=...
```

### Step 5: Upload to Play Console & test
