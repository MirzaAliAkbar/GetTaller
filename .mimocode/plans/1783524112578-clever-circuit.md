# Fix: Notifications Broken in Release Build (Play Store)

## Confirmed Root Cause
Crashlytics shows: `PlatformException: Missing type parameter` from `Gson.TypeToken` in `flutter_local_notifications`. R8 with `proguard-android-optimize.txt` strips Gson TypeToken generic signatures, breaking notification deserialization in `ScheduledNotificationReceiver`.

Debug works because `minifyEnabled` is `false`.

## Three Fixes

### Fix 1: Add ProGuard rules for flutter_local_notifications
**File:** `android/app/proguard-rules.pro`

Add rules to keep the plugin package, Gson TypeToken, and TypeAdapter patterns.

### Fix 2: Add missing Android permissions
**File:** `android/app/src/main/AndroidManifest.xml`

Add `RECEIVE_BOOT_COMPLETED` (required for notification reschedule after reboot) and `SCHEDULE_EXACT_ALARM` (for reliable scheduling on Android 12+).

### Fix 3: Switch to safer ProGuard base
**File:** `android/app/build.gradle`

Change `proguard-android-optimize.txt` → `proguard-android.txt` to disable aggressive optimization passes.
